- **Specification:** DIMER Notebook Specification 2.2, profile `TASK-INFERENCE`, mode `GUIDED` (no fine-tuning: the model is used as published).
- **Standalone:** generated by `tools/build_notebook.py` (`build_notebook.py/3.0`). The notebook carries the package, the stage runner `tools/tutorial_stages.py`, the hash-locked `tutorials/requirements-colab.lock.txt`, the snapshot manifest and the licence, and verifies each against its SHA-256. It needs no repository clone, no DIMER worker and no credential.
- **Isolated environment:** nothing is installed into the notebook kernel. A pinned `uv` wheel (size and SHA-256 checked) builds a CPython 3.12.12 virtual environment and installs the lock with `--require-hashes --only-binary :all:`; every stage runs there as a subprocess with Hugging Face tokens removed and `MPLBACKEND=Agg`, so no runtime restart is needed. Linux x86_64 only; other platforms are refused in Section 1.
- **Pin status:** pinned to commit `c69ef3e` on 2026-10-05; Section 3 verifies every file before any load. See `STATUS.md`.
- **Model download:** about 49 MB (SafeTensors only). Sample download: about 2.5 MB.
- **Outputs:** under `outputs/swin2sr_x4_super_resolution/<run id>/outputs/`: input manifest, inputs CSV, per-image scores CSV, panels, every 4× output PNG, evaluation report, predictions CSV and the result/provenance JSON; the optional activity and BYOD branches add their own JSON and images.
- **Execution evidence:** Google Colab T4 runs of blob `caa2969` (2026-10-05, not a strictly fresh session) and of blob `a63fdd43` (2026-10-09, fresh session, executed notebook in `docs/execution-evidence/2026-10-09-34eac6c/`), both recorded in `docs/release-verification.md`. A CPU pre-flight with a tiny random-initialised snapshot is recorded in `docs/release-verification.md`; it is not release evidence.
